# Onyx 0.6.11

**Before you download:** Onyx needs either the Claude Code CLI signed in to a paid claude.ai plan, or the Codex CLI signed in with ChatGPT. Onyx does not use API keys or metered API billing. This release runs on Apple Silicon (arm64) Macs with macOS 13 or newer.

On 0.6.5 or later, choose **Onyx ▸ Check for Updates…** and it installs this one for you. On anything earlier, download `Onyx-0.6.11-macOS-arm64.dmg`, open it, and drag Onyx to Applications. The app is signed with a Developer ID certificate and notarized by Apple. To verify a download, place its matching `.sha256` file beside it and run `shasum -a 256 -c <filename>.sha256`.

## Split view

- **Read two pages side by side.** Right-click a note or artifact in the sidebar and choose **Open in Split View**, or ⌥-click a link to a page. It opens beside the page you're reading.
- **Drag a tab down onto the page** to split it there: the half it would take is outlined, and it goes where you let go. Esc cancels.
- **Right-click a tab** for **Split Left**, **Split Right**, **Close Split**, **Close Tab** and **Close Other Tabs**.
- **The half you last clicked into is the one you're reading**, marked by a thin accent line. The sidebar, ⌘F, the outline and Back act on it.
- **Drag the divider** to resize, double-click it to even the halves, or click the **×** on it to go back to one page. Closing either tab also ends the split. The split comes back after a relaunch.

## Tabs

- **Drag a tab along the bar** to put it in a new place. The order is kept, and ⌘1–9 and the tab list follow it.

## Fixes

- **Pages that build images in their own scripts draw them again.** An image tag written inside a script was having its path rewritten, which broke every image such a page drew.
