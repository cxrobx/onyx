# Onyx 0.6.6

**Before you download:** Onyx needs either the Claude Code CLI signed in to a paid claude.ai plan, or the Codex CLI signed in with ChatGPT. Onyx does not use API keys or metered API billing. This release runs on Apple Silicon (arm64) Macs with macOS 13 or newer.

On 0.6.5, choose **Onyx ▸ Check for Updates…** and it installs this one for you. On anything earlier, download `Onyx-0.6.6-macOS-arm64.dmg`, open it, and drag Onyx to Applications. The app is signed with a Developer ID certificate and notarized by Apple. To verify a download, place its matching `.sha256` file beside it and run `shasum -a 256 -c <filename>.sha256`.

## Rearrange your notes in the sidebar

Notes, and your other notes vaults, now reorganise the way Artifacts does. Drag a note or a folder onto another folder, or onto the tree's empty space to move it to the top. Right-click for **Move To…**, a folder list you can type to filter; **Rename**, which keeps a note's `.md`; and **New Folder**. An empty folder now shows in the tree, so it can take a drop.

Obsidian only updates links for moves made inside Obsidian, so Onyx updates them for its own. A `[link](../Folder/Note.md)` or an image that the move would break is rewritten from the new location, in the same style. A `[[wikilink]]` that would now lead somewhere else is rewritten to the shortest form that works, with its heading and alias kept. Code is left alone. If you edit a note while it is being updated, your edit wins and the toast names that note. Notes inside a linked folder belong to another folder outside the vault, so Onyx names them in the toast but doesn't edit them.

A note's asks, highlights and reading position now follow it when it moves or is renamed. That holds in Artifacts too.

## Rename an Artifacts page

**Rename** now works on Artifacts pages as well as folders. It changes the name Onyx shows the page by. The page's file and its `<title>` stay as they are. **Use Page Title** puts the title back.

## More of Obsidian's formatting

- **Callouts** (`> [!info] Title`) render as Obsidian draws them, in each type's colour and icon. `[!faq]-` starts folded, `[!faq]+` starts open, and callouts can nest.
- **`%%comments%%`** are hidden, whether inline or spread over several lines.
- **`#tags`** in a note show as tags.
- **Bare web addresses** are links.
- **A single line break** in a vault note is now shown as one, as Obsidian shows it by default.

The ⌘E editor shows callouts, tags and addresses too, and greys out comments.
