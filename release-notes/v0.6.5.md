# Onyx 0.6.5

**Before you download:** Onyx needs either the Claude Code CLI signed in to a paid claude.ai plan, or the Codex CLI signed in with ChatGPT. Onyx does not use API keys or metered API billing. This release runs on Apple Silicon (arm64) Macs with macOS 13 or newer.

On 0.6.4, choose **Onyx ▸ Check for Updates…** and it installs this one for you. On anything earlier, download `Onyx-0.6.5-macOS-arm64.dmg`, open it, and drag Onyx to Applications. The app is signed with a Developer ID certificate and notarized by Apple. To verify a download, place its matching `.sha256` file beside it and run `shasum -a 256 -c <filename>.sha256`.

## More than one vault

**Settings ▸ Vaults ▸ Other vaults** adds more notes vaults beside your main one. Each appears under Notes with a heading of its own, after your main vault's tree, and in Library between Notes and Artifacts. A note in another vault follows its own vault's `[[links]]`, so two vaults can each have a note with the same name. Answers about it read that vault as their folder. Its notes use that vault's reading styles once Obsidian has measured them, and your main vault's until then.

Your main vault stays the one the app's colours follow.

## Search one vault or all of them

**⌘P** searches your main vault and Artifacts by default, or every vault if you choose **⌘P searches: Every vault** in Settings. A switch in the search box, or **⌥S**, flips it for one search. Searching inside another vault's pages uses the index vault-mcp already keeps for it. A vault without one is still found by title, and the search box says so.

## Color theme follows the vault's modes

With **Match vault appearance** on, **Color theme** now picks which of your vault's colour modes Onyx wears: Same as Obsidian (as before), System, Light or Dark. It is no longer greyed out.

## Remove from Recents

Right-click a card under Recently opened, or a Recent ask, on the Library home page and choose **Remove from Recents**. It only hides the item. Your reading history and saved answers stay as they were.
