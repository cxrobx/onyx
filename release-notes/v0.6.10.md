# Onyx 0.6.10

**Before you download:** Onyx needs either the Claude Code CLI signed in to a paid claude.ai plan, or the Codex CLI signed in with ChatGPT. Onyx does not use API keys or metered API billing. This release runs on Apple Silicon (arm64) Macs with macOS 13 or newer.

On 0.6.5 or later, choose **Onyx ▸ Check for Updates…** and it installs this one for you. On anything earlier, download `Onyx-0.6.10-macOS-arm64.dmg`, open it, and drag Onyx to Applications. The app is signed with a Developer ID certificate and notarized by Apple. To verify a download, place its matching `.sha256` file beside it and run `shasum -a 256 -c <filename>.sha256`.

## A page is open in one tab

- **Opening a page that's already open goes to its tab** instead of opening a second one. That covers ⌘-click and middle-click, the sidebar's Open in New Tab, ⌘↩ in search, and links that ask for a new window.
