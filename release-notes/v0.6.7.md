# Onyx 0.6.7

**Before you download:** Onyx needs either the Claude Code CLI signed in to a paid claude.ai plan, or the Codex CLI signed in with ChatGPT. Onyx does not use API keys or metered API billing. This release runs on Apple Silicon (arm64) Macs with macOS 13 or newer.

On 0.6.5 or later, choose **Onyx ▸ Check for Updates…** and it installs this one for you. On anything earlier, download `Onyx-0.6.7-macOS-arm64.dmg`, open it, and drag Onyx to Applications. The app is signed with a Developer ID certificate and notarized by Apple. To verify a download, place its matching `.sha256` file beside it and run `shasum -a 256 -c <filename>.sha256`.

## Moving notes in the sidebar, smoothed out

- **A dropped note lands at once.** Before, the sidebar waited while Onyx checked the whole vault for links to update, which took several seconds in a large vault, so a drop could look as if it hadn't worked. That check is now many times faster, and the row moves the moment you let go. If the move can't be made, the row goes back and the toast says why.
- **Tabs follow what you move.** A tab showing a note you moved or renamed now opens it from its new place, still in its vault, so its asks keep the right context. A tab whose answer panel was open follows too. One still writing an answer finishes first, and follows the next time you show it.
- **Back finds a moved page.** Going Back, or following an old link, to a page you moved opens it where it now lives instead of failing.
