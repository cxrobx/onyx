# Onyx 0.6.8

**Before you download:** Onyx needs either the Claude Code CLI signed in to a paid claude.ai plan, or the Codex CLI signed in with ChatGPT. Onyx does not use API keys or metered API billing. This release runs on Apple Silicon (arm64) Macs with macOS 13 or newer.

On 0.6.5 or later, choose **Onyx ▸ Check for Updates…** and it installs this one for you. On anything earlier, download `Onyx-0.6.8-macOS-arm64.dmg`, open it, and drag Onyx to Applications. The app is signed with a Developer ID certificate and notarized by Apple. To verify a download, place its matching `.sha256` file beside it and run `shasum -a 256 -c <filename>.sha256`.

## Links to the web open in your browser

- **A link to a website opens in your default browser.** Before, it loaded inside Onyx, with no address bar and no way out but Back, and a link in a Markdown note replaced the whole window. Now Onyx stays on the page you were reading.
- **⌘-click and middle-click go to the browser too.** A site doesn't get an Onyx tab of its own.
- **Mail and other app links open in their own apps.** A `mailto:` link opens your mail app, and an `obsidian://` link opens Obsidian.
- **Links between your own notes and artifacts are unchanged.** They still open in Onyx, in the tab you're reading.

## Artifacts follow pages you move in Finder

- **A page moved or renamed outside Onyx stays in Artifacts.** Artifacts entries are links to your files, so moving a file in Finder used to leave its entry pointing at nothing. Onyx now remembers each linked file, notices when one moves, and points the entry at its new place, with the same name, pins, asks and highlights. A file moved to the Trash is left missing on purpose.
- **A missing page offers a fix.** Right-click a page marked *missing* and Onyx offers **Relink to** the file of that name it found nearby or through Spotlight, or **Choose New Location…** to pick it yourself. This also fixes entries that broke before this update, since Onyx couldn't have recorded them yet.
- Onyx can follow a file only on the Mac where it was linked, and only while it stays on the same disk. A file moved to another disk gets the *Relink to* offer instead.
