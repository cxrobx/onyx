# Onyx 0.6.9

**Before you download:** Onyx needs either the Claude Code CLI signed in to a paid claude.ai plan, or the Codex CLI signed in with ChatGPT. Onyx does not use API keys or metered API billing. This release runs on Apple Silicon (arm64) Macs with macOS 13 or newer.

On 0.6.5 or later, choose **Onyx ▸ Check for Updates…** and it installs this one for you. On anything earlier, download `Onyx-0.6.9-macOS-arm64.dmg`, open it, and drag Onyx to Applications. The app is signed with a Developer ID certificate and notarized by Apple. To verify a download, place its matching `.sha256` file beside it and run `shasum -a 256 -c <filename>.sha256`.

## ⇧⌘W closes a tab

- **⇧⌘W closes the tab you're reading**, the way it does in a browser. Before, it closed the whole window, and Close Tab had no shortcut.
- **On the last tab, ⇧⌘W closes the window.**
- **Close Window moves to ⌥⌘W.** ⌘W still hides Onyx, as before.
