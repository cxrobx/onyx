# Onyx 0.6.13

**Before you download:** Onyx needs either the Claude Code CLI signed in to a paid claude.ai plan, or the Codex CLI signed in with ChatGPT. Onyx does not use API keys or metered API billing. This release runs on Apple Silicon (arm64) Macs with macOS 13 or newer.

On 0.6.5 or later, choose **Onyx ▸ Check for Updates…** and it installs this one for you. On anything earlier, download `Onyx-0.6.13-macOS-arm64.dmg`, open it, and drag Onyx to Applications. The app is signed with a Developer ID certificate and notarized by Apple. To verify a download, place its matching `.sha256` file beside it and run `shasum -a 256 -c <filename>.sha256`.

## Lists in the editor (⌘E) type as Obsidian does

Checked by typing the same keys into Obsidian and into the editor.

- **A long item hangs.** A bullet, a nested bullet, a task or a numbered item that wraps carries on under its text, not back under its marker, in a quote or a callout too.
- **Shift+Enter, then Enter.** A line added with Shift+Enter lines up under the item's text (past a task's box), and Enter from it starts the next item: numbered on, with a new box for a task.
- **Backspace after a marker** takes the space, as Obsidian does, instead of turning the marker into hidden indent.
- **Leaving a quote** leaves a blank line after it, so the next line isn't read as part of the quote. An empty item in a quote ends the list and keeps you in the quote.
