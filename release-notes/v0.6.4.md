# Onyx 0.6.4

**Before you download:** Onyx needs either the Claude Code CLI signed in to a paid claude.ai plan, or the Codex CLI signed in with ChatGPT. Onyx does not use API keys or metered API billing. This release runs on Apple Silicon (arm64) Macs with macOS 13 or newer.

Download `Onyx-0.6.4-macOS-arm64.dmg`, open it, and drag Onyx to Applications. The app is signed with a Developer ID certificate and notarized by Apple. To verify a download, place its matching `.sha256` file beside it and run `shasum -a 256 -c <filename>.sha256`.

## Updates now arrive automatically

Onyx checks for a new release once a day and, when there is one, tells you what changed and asks before it installs anything. **Onyx ▸ Check for Updates…** checks right away. Updating quits Onyx, replaces it, and opens the new version.

Each update is signed by us as well as by Apple. Onyx verifies the signature before it unpacks the download and refuses an archive that does not match, so an update can only be one we published.

**If you are on 0.6.3 or earlier, install this one version by hand.** Choose **Onyx ▸ Check for Updates…**, which opens this page, download the disk image above and drag Onyx to Applications. Every release after this one arrives inside the app.

## The background service follows the app

If you keep Onyx's background service running (`scripts/install-daemon.sh`), an update used to leave it running the old version's code until you restarted it. Onyx now notices, on launch, that the service it found is not the version of the app in front of you, and restarts it.
